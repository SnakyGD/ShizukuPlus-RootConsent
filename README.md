# About this fork

By default, Shizuku+ automatically grants full access to apps that connect to the service when the daemon runs as root.

This fork disables automatic grants: apps must request access, and the user must approve the request.

Builds are available from [GitHub Actions](https://github.com/SnakyGD/ShizukuPlus/actions/workflows/app.yml).
